# Documentation Rules
<!-- version: 1.1.0 -->
- **Version Markers:** Every `.md` file MUST have a version marker.
- **Updates:** Update `repo-state.md` on significant architectural changes.
- **Feature Docs:** Every new feature, integration, or major UI component must ship with a `docs/FEATURE-<name>.md` documenting architecture, config, and user workflow. Use `docs/FEATURE-DOC-TEMPLATE.md` as the starting point. Version marker required.
